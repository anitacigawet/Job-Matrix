# Changelog

## 1.0.0 — 2026-08-31

- Job Matrix runs as a local application with no Job Matrix account or remote
  application backend.
- Downloadable runtime packages and launchers mean ordinary use does not
  require the development toolchain.
- The public showroom uses the real interface and workflows with deterministic
  fictional data in place of the backend.
- Includes saved search criteria, multi-source job search, mismatch filtering,
  duplicate grouping, fit scoring, application tracking, exports, and guided
  application preparation.
- Packaged database migrations and the optional JobSpy scraper are available
  from the same runtime layout used by the application.
