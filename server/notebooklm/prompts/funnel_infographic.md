# Search Funnel Infographic — design notes

INSTRUCTIONAL style + LANDSCAPE orientation gives a horizontal flow that reads naturally for a funnel. The user can save and share with a coach to talk through where their search is leaking.

## Instructions (sent to Studio)

Design a single-page **landscape** infographic showing the listener's job-search funnel for the trailing seven days. The visual idiom is a classic conversion funnel — wide at the top, narrowing at each stage as candidates / applications drop out.

**Required stages, left-to-right.**

1. **Jobs scanned.** Total raw listings the scrapers surfaced this week.
2. **AI-eligible.** Listings that passed the multi-stage LLM filter (not flagged as ineligible, scam, MLM, mismatched education, etc.).
3. **High-fit.** Listings scoring above a fit threshold (default ≥75%, but reflect whatever's in the source data).
4. **Applied.** Listings the listener actually applied to.
5. **Response received.** Applications that got *any* response (interview invite, rejection, automated acknowledgement — but ideally separated where the data allows).
6. **Interview stage.** Applications now in active interview pipeline.
7. **Offer stage.** Applications at the offer / verbal stage.

For each stage, show:
- The **count** (large, legible).
- The **conversion rate** from the previous stage (smaller, secondary number, e.g. "32%").
- A small caption / takeaway if relevant ("biggest drop-off here").

**Insight block.**

Below or beside the funnel, a small panel with two or three concrete observations:
- Where the largest drop-off is.
- One actionable suggestion grounded in the data ("Most drop-off is at the application stage — the listener is finding good matches but not submitting. Consider a daily applications target.")
- If conversion rates look healthy, say so — don't manufacture a problem.

**Style constraints.**

- INSTRUCTIONAL style — geometric, schematic, slightly textbook-feeling. Not playful, not stark.
- One accent colour for the funnel itself, neutral backgrounds, one secondary colour for the insight callouts.
- High-contrast numbers. Stage labels readable but secondary to the numbers.
- Subtle gridlines, no busy decoration.

**Forbidden.**

- Inventing conversion rates if the underlying data is missing (e.g. if response data isn't tracked, mark that stage "—" rather than guess).
- Stylising the funnel into a gimmick (jar, glass, hourglass). Keep it abstract and clean.
- Hustle-culture vocabulary in the insight block.

**Title.** "Job Matrix — Search Funnel, week ending [date]". One-line subtitle: "Trailing 7 days."
